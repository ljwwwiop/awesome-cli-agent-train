## How to Contribute

1. Fork this repository
2. Add papers to the corresponding category
3. Submit a PR

Format Guidelines:
- Date format: `YYYY-MM-DD`
- Institute: first author's institution
- Paper format: `[Title](link)`
- Publication options: `Arxiv`, `CVPR`, `ICML`, `NeurIPS`, etc.
- Tags: 2-3 keywords, separated by commas
